泰拉瑞亚世界文件保存在哪里？

Terraria 把每个世界保存成一个 .wld 文件，把每个角色对世界的已探索地图保存成 .map 文件。下面是它们的位置，以及如何用 TerraMap 查看。

Windows

世界文件：

%USERPROFILE%\Documents\My Games\Terraria\Worlds

玩家地图文件在以角色命名的文件夹里，位于：

%USERPROFILE%\Documents\My Games\Terraria\Players

把其中任一路径粘贴到文件资源管理器的地址栏里就能直接打开。如果你的“文档”文件夹由 OneDrive 备份， 请改看 %USERPROFILE%\OneDrive\Documents\My Games\Terraria。

macOS

~/Library/Application Support/Terraria/Worlds
~/Library/Application Support/Terraria/Players

Library 文件夹默认是隐藏的。在访达中选择 前往 → 前往文件夹… （Shift+Cmd+G），然后粘贴路径。

Linux 和 Steam Deck

~/.local/share/Terraria/Worlds
~/.local/share/Terraria/Players

.local 是隐藏文件夹。在大多数文件管理器里按 Ctrl+H 可以显示它。

Steam 云世界

保存在 Steam 云里的世界和角色则放在 Steam 自己的目录里，按你的 Steam 用户 ID 和 Terraria 的 App ID（105600）分目录：

  • Windows： C:\Program Files (x86)\Steam\userdata\{YOUR_USER_ID}\105600\remote
  • macOS： ~/Library/Application Support/Steam/userdata/{YOUR_USER_ID}/105600/remote
  • Linux： ~/.local/share/Steam/userdata/{YOUR_USER_ID}/105600/remote

如果 userdata 下有多个数字文件夹，逐个进去看看哪个里面有 105600 文件夹。

在 TerraMap 中打开世界

  • 打开文件夹（就是上面的 Terraria 文件夹）可以选择世界和角色。只会显示这个角色探索过的部分， 不会有剧透。
  • 打开世界文件，或者把 .wld 文件拖到页面上，可以看到整个世界。

TerraMap 是只读的，完全在浏览器里运行，你的世界文件不会被上传或修改。桌面版 会自动找到你的世界和角色，包括 Steam 云存档。
